Format Decode · 02

3D格式解码：左右、上下与蓝光3D

栏目二｜这是3d电影网被查阅最多的一组内容。同一个立体视频文件，命名里的「SBS」「OU」「ISO」决定了它该用哪种播放方式，搞错就会出现重影或上下压扁。

FORMAT / 01

左右格式（Side-by-Side / SBS）

左右两路画面并列压缩进一帧，是家用3D电视与网络片源最常见的封装方式，也是3D蓝光原盘最常见的存储形态。

  • 半宽SBS分辨率压缩，画质有可见损耗
  • 全宽SBS需播放器或电视支持自动识别
  • 3D电视需在信号设置里选「左右」而非「上下」
  • 老款快门眼镜多对应此格式
FORMAT / 02

上下格式（Top-and-Bottom / OU）

两路画面上下堆叠，垂直方向分辨率减半，移动端VR盒子与部分便携播放器偏爱这种封装。

  • 命名常见 HSBS、OU、TB 字样
  • 播放器设置必须与文件封装方向一致
  • VR头显投屏场景兼容性较好
  • 投影幕场景下需留意画面比例变形
FORMAT / 03

蓝光3D原盘（BD3D / MVC）

采用MVC多视点编码，左眼为完整1080p、右眼为差值补充，体积大但画质保留最完整，是正片收藏的主流规格。

  • ISO与BDMV两种目录结构均属蓝光原盘
  • 需支持3D解密的播放机或软件
  • 字幕需单独挂载并匹配帧率
  • 不建议二次转码，容易破坏视差信息
FORMAT / 04

帧连续与帧封装（Frame Sequential）

左右眼画面交替逐帧输出，靠快门眼镜同步开合，对刷新率要求高，是早期3D显示器的典型方案。

  • 需要 120Hz 及以上刷新率支持
  • 信号线带宽不足会直接降为2D
  • 眼镜需与显示设备同品牌配对
  • 长片观看建议中途摘镜休息

怎么判断家里现有的设备到底支不支持3D？

先看显示设备说明书里是否写明「3D显示」及对应制式，再核对接口版本与刷新率。只有面板支持还不够，播放端、线材与眼镜三者制式必须一致。3d电影网建议在购买片源前，先用一段免费的3D测试片验证整条链路，避免文件买回来却无法出屏。

3D电视和投影幕，哪种更适合普通客厅？

电视的优势是亮度足、设置简单、佩戴主动快门眼镜即可；投影的优势是屏幕尺寸与沉浸感，但对环境光极敏感，暗场亮度不足时立体感会被明显削弱。客厅采光强优先电视，有独立遮光影音室才考虑投影。

播放器输出设置里最容易被忽略的三项是什么？

第一是3D格式匹配，必须选对左右或上下；第二是输出帧率，24p影片建议保持原帧率以减少抖动；第三是色深与色彩空间，10bit片源若被压成8bit会出现色带。三项任何一项不匹配，都会出现重影或画面发灰。

看3D多久该休息一次？儿童能看吗？

成人连续观看建议控制在40至60分钟，摘下眼镜远眺放松眼部调节。六岁以下儿童视觉系统仍在发育，不建议长时间观看立体影像；有斜视或弱视情况应先咨询眼科医生。感到头晕时立即停用，不要硬撑。

原生3D拍摄和后期转制，观感差在哪？

原生3D在拍摄时就用双镜头模拟人眼间距，景深层次与物体边缘的过渡自然，前景出屏不会撕裂；后期转制是平面画面人工分层推深，常见问题是主体抠像边缘穿帮、背景糊成一层、快速运动镜头出现错位。选片时留意片方是否标注「原生3D拍摄」。

网络上的3D片源清晰度参差不齐，怎么判断？

先看分辨率标注是否写清是单眼1080p还是整帧1080p，半宽SBS的单眼实际只有540p水平像素；再看码率，高码率能保住暗场细节；最后看评论里关于字幕与音轨的反馈。不要只看文件大小下结论。

常见问题：读者提问最多的话题

栏目六｜问题来自读者实际遇到的操作障碍，不是生造的伪问答。如果你的问题不在列表里，可以通过页面底部的方式联系我们补充。

为什么播放3D文件后画面是左右两个重影？

播放器或电视的3D模式未开启，或格式选成了「上下」。进入信号设置手动指定与文件一致的左右/上下制式即可合并出屏。

4K电视能提升3D画质吗？

面板的4K分辨率本身不改变3D源的分辨率，但更高的像素密度能减轻左右眼画面叠加后的纱窗效应，观感会更干净。

蓝光3D原盘能直接拷进硬盘播放吗？

ISO与BDMV结构需要播放机支持3D解密与MVC解码。普通电视内置播放器大多无法识别，建议先确认设备规格再拷贝。

为什么有的3D片看起来头晕？

常见原因是视差过大、快速横摇镜头或眼镜同步失配。调低画面亮度、增大观看距离、缩短单次时长都能缓解。

左右格式和上下格式能互相转换吗？

可以，用支持立体视频重排的工具即可，但重排不改变源分辨率，半宽SBS转上下后单眼清晰度仍是受限的。
